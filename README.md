# US Stock Daily Brief

Static research brief published from a private decision-support project.

**What this is:** a daily list of screened US equity/ETF candidates with a score,
the last close, and pre-registered stop / first-target levels.

**What this is not:** investment advice, an order instruction, or a personalised
recommendation. It contains no account balance, no holdings, and no position
sizing. Levels are as of the scan timestamp shown on the page and must be
re-checked against live quotes before any use.
